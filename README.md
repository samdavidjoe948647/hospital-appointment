# 🏥 Hospital Appointment Management System

A full-stack Hospital Appointment Management System developed using Django.

## 🚀 Features

- 👤 Patient Registration & Login
- 👨‍⚕️ Doctor Management
- 📅 Appointment Booking
- 🔄 Appointment Rescheduling
- ❌ Appointment Cancellation
- 🔑 Admin Dashboard
- 📋 Patient Records
- 🔒 Authentication System

## 🛠 Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- Bootstrap
- SQLite3

## 📂 Project Structure

```
Hospital Appointment/
│
├── appointments/
├── admin_portal/
├── patients/
├── hospital_project/
├── templates/
├── static/
├── manage.py
└── db.sqlite3
```

## ⚙️ Installation

```bash
git clone https://github.com/samdavidjoe948647/hospital-appointment.git

cd hospital-appointment

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
